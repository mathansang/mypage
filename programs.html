Npzee

Data Utility

NumPy의 Npz·Npy 파일을 비롯해 Csv, Txt, Xlsx까지 지원하는 그리드 데이터 뷰어입니다. 대용량 수치 배열 데이터를 표 형태로 빠르게 열람·탐색할 수 있으며, Windows 스토어와 웹에서 이용할 수 있습니다.

MxDevTool

Dev Suite

QuantLib-Python 기반의 금융 분석 통합 개발 라이브러리입니다. 경제 시나리오 생성(ESG), 자산부채관리(ALM), 파생상품 프라이싱을 지원하며 Hull-White·Black-Karasinski·Vasicek·CIR 등 확률 모형과 몬테카를로 시뮬레이션을 제공합니다.

WaterMelon

Market Data View

다양한 웹 데이터 및 데이터 공급자의 데이터를 가공해 원하는 지표를 생성하고, 통합 모니터링으로 급변하는 금융·암호화폐 자산관리에 빠르게 대응할 수 있는 데스크톱 애플리케이션입니다. Python 기반 Backend Engine으로 여러 데이터 소스를 함께 관리하고, 실시간·스냅샷 데이터 확인, 테마 변경, 과거 데이터 저장 및 엑셀보내기를 지원합니다.
