Swaption

Swaption(notional, optionTenor, swapTenor, strike, swapSide, tradeDate, swaptionCode, normalVol, curveData, valueDate, outputType)
← 지원 함수 목록으로
  1. 개요

    금리스왑션의 가격과 Delta·Vega 등 민감도를 산출합니다.

  2. 입력 파라미터
    • notional명의금액
    • optionTenor옵션 만기 테너 (예: 1Y)
    • swapTenor기준 스왑 만기 (예: 5Y)
    • strike행사가기 금리. 숫자 또는 atm
    • swapSide레그 방향. rec(고정 수취)·pay(고정 지급)
    • tradeDate거래 체결일
    • swaptionCode스왑션 컨벤션 코드 (예: swaption_krw_cd)
    • normalVol노머 볼라틸리티 (연간 비율)
    • curveData할인 곡선 데이터 (NPV 계산용)
    • valueDate평가일 (YYYY-MM-DD)
    • outputType출력 유형. pricing·cashflow·greeks·input_items 등
  3. API
    • POST /xlfunction/Swaption
    • Excel Function·C#·Python 클라이언트에서 동일한 함수명으로 호출
