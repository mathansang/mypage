GeneralSwap

GeneralSwap(inputData)
← 지원 함수 목록으로
  1. 개요

    커스텀 스케줄·레그 구조를 가진 일반 스왑을 평가합니다. inputData 테이블에 레그별 조건을 정의합니다.

  2. 입력 파라미터
    • inputData일반 스왑 입력 테이블 (name·value). 거래 정보와 leg1/leg2 조건을 정의
  3. API
    • POST /xlfunction/GeneralSwap
    • Excel Function·C#·Python 클라이언트에서 동일한 함수명으로 호출
