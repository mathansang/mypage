ForwardRateFromYC

ForwardRateFromYC(curveData, forwardStartDates, forwardEndDates, compounding, frequency)
← 지원 함수 목록으로
  1. 개요

    yield curve로부터 지정 구간의 전방 금리를 계산합니다.

  2. 입력 파라미터
    • curveData곡선 데이터 (zeroRate 또는 discount). time/tenor·zeroRate 또는 quote 테이블. refDate가 포함된 곡선 필요
    • forwardStartDates전방 금리 시작일 목록
    • forwardEndDates전방 금리 종료일 목록 (시작일과 동일 길이)
    • compounding복리 방식 (cont, annual 등). 기본 cont
    • frequency복리 주기 (annual 등). compounding이 compounded일 때 사용
  3. API
    • POST /xlfunction/ForwardRateFromYC
    • Excel Function·C#·Python 클라이언트에서 동일한 함수명으로 호출
