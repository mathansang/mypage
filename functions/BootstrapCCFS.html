BootstrapCCFS

BootstrapCCFS(refDate, fixedQuoteData, curveType, baseCurveData, fxRate)
← 지원 함수 목록으로
  1. 개요

    교차통화 고정금리 스왑 견적으로 외화 할인 곡선을 부트스트랩합니다.

  2. 입력 파라미터
    • refDate기준일. 곡선 부트스트랩 및 할인 계산의 기준 날짜 (YYYY-MM-DD)
    • fixedQuoteDataCCFS 고정금리 스왑 견적 테이블. 헤더: tenor, type, quote 컬럼
    • curveTypeCCFS 곡선 컨벤션 코드
    • baseCurveData기준통화 인덱스 곡선 데이터 (time/tenor·zeroRate 또는 quote 테이블)
    • fxRate기준통화 대 외화 환율
  3. API
    • POST /xlfunction/BootstrapCCFS
    • Excel Function·C#·Python 클라이언트에서 동일한 함수명으로 호출
  4. 샘플 요청 BootstrapCCFS.json 
    {
  "args": [
    {
      "refDate": "2024-01-02",
      "fixedQuoteData": [
        [
          "tenor",
          "type",
          "quote"
        ],
        [
          "1Y",
          "swap",
          0.03
        ]
      ],
      "curveType": "zero_krw_cd",
      "baseCurveData": [
        [
          "tenor",
          "type",
          "quote"
        ],
        [
          "1Y",
          "deposite",
          0.028
        ]
      ],
      "fxRate": 1300,
      "optionArg": ""
    }
  ]
}
