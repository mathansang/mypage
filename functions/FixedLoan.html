FixedLoan

FixedLoan(principal, balance, maturity, fixedRate, loanSide, loanDate, loanCode, gracePeriod, curveData, defaultData, earlyRedemRate, valueDate, outputType)
← 지원 함수 목록으로
  1. 개요

    고정금리 대출의 NPV, 상환 스케줄 및 부도 반영 평가를 수행합니다.

  2. 입력 파라미터
    • principal대출 원금
    • balance현재 잔액 (상환 계산 기준)
    • maturity만기. 날짜 또는 테너 (예: 10Y)
    • fixedRate고정금리 (연간 비율)
    • loanSide대출 방향. buy(long)·sell(short)
    • loanDate대출 실행일
    • loanCode대출 컨벤션 코드 (예: loan_krw_fixed)
    • gracePeriod원리금 상환 거치 기간 (월 또는 회차)
    • curveData할인 곡선 데이터 (NPV 계산용)
    • defaultData부도확률 곡선 (신용 평가용). 선택
    • earlyRedemRate중도상환 수수료율
    • valueDate평가일 (YYYY-MM-DD)
    • outputType출력 유형. pricing·cashflow·greeks·input_items 등
  3. API
    • POST /xlfunction/FixedLoan
    • Excel Function·C#·Python 클라이언트에서 동일한 함수명으로 호출
