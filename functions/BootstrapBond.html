BootstrapBond

BootstrapBond(refDate, yieldQuoteData, curveType)
← 지원 함수 목록으로
  1. 개요

    채권 Par·YTM 견적으로 할인·스팟 금리 곡선을 구축합니다.

  2. 입력 파라미터
    • refDate기준일. 곡선 부트스트랩 및 할인 계산의 기준 날짜 (YYYY-MM-DD)
    • yieldQuoteData채권 견적 테이블. 헤더: tenor, type, quote 컬럼 (type은 deposite·swap·bond 등)
    • curveType곡선 컨벤션 코드 (예: zero_krw_cd). 일수계산·캘린더·부트스트랩 방식을 정의
  3. API
    • POST /xlfunction/BootstrapBond
    • Excel Function·C#·Python 클라이언트에서 동일한 함수명으로 호출
