VanillaSwap

VanillaSwap(notional, maturityTenor, fixedRate, swapSide, tradeDate, swapCode, curveData, valueDate, outputType)
← 지원 함수 목록으로
  1. 개요

    이자율 스왑(고정 vs 변동)의 NPV, 레그 PV, DV01을 산출합니다.

  2. 입력 파라미터
    • notional명의금액
    • maturityTenor만기 테너 (예: 5Y, 10Y)
    • fixedRate고정금리 (연간 비율)
    • swapSide레그 방향. rec(고정 수취)·pay(고정 지급)
    • tradeDate거래 체결일
    • swapCode스왑 컨벤션 코드 (예: swap_krw_cd)
    • curveData할인 곡선 데이터 (NPV 계산용)
    • valueDate평가일 (YYYY-MM-DD)
    • outputType출력 유형. pricing·cashflow·greeks·input_items 등
  3. API
    • POST /xlfunction/VanillaSwap
    • Excel Function·C#·Python 클라이언트에서 동일한 함수명으로 호출
