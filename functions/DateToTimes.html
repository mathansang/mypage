DateToTimes

DateToTimes(dates, refDate, daycounter)
← 지원 함수 목록으로
  1. 개요

    날짜를 기준일 대비 연 단위 경과 시간으로 변환합니다.

  2. 입력 파라미터
    • dates변환할 날짜 목록
    • refDate기준일. 비어 있으면 오늘 날짜
    • daycounter일수계산 기준 (예: Act365). 기본 Act365
  3. API
    • POST /xlfunction/DateToTimes
    • Excel Function·C#·Python 클라이언트에서 동일한 함수명으로 호출
  4. 샘플 요청 DateToTimes.json 
    {
  "args": [
    {
      "dates": [
        "2024-06-01",
        "2025-06-01"
      ],
      "refDate": "2024-01-02",
      "daycounter": "Act365Fixed"
    }
  ]
}
