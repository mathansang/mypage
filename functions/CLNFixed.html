CLNFixed

CLNFixed(notional, maturityTenor, fixedRate, issueDate, bondCode, defaultCurveData, curveData, valueDate, outputType)
← 지원 함수 목록으로
  1. 개요

    고정금리 신용연계채권(CLN)의 가격을 산출합니다.

  2. 입력 파라미터
    • notional명의금액
    • maturityTenor만기 테너 (예: 5Y, 10Y)
    • fixedRate고정금리 (연간 비율)
    • issueDate발행일 또는 체결일
    • bondCode채권 컨벤션 코드 (예: bond_krw_ktb)
    • defaultCurveData부도확률 곡선 (신용 평가용)
    • curveData할인 곡선 데이터 (NPV 계산용)
    • valueDate평가일 (YYYY-MM-DD)
    • outputType출력 유형. pricing·cashflow·greeks·input_items 등
  3. API
    • POST /xlfunction/CLNFixed
    • Excel Function·C#·Python 클라이언트에서 동일한 함수명으로 호출
