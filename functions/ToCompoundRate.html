ToCompoundRate

ToCompoundRate(dateOrTimes, contiRate, freqPerYear, dayCounter, calendar, refDate)
← 지원 함수 목록으로
  1. 개요

    연속복리 금리를 지정 복리 주기의 복리 금리로 변환합니다.

  2. 입력 파라미터
    • dateOrTimes금리 변환 기준 일자 또는 time
    • contiRate입력 연속복리 금리 배열
    • freqPerYear목표 복리 주기 (연 간 횟수)
    • dayCounter일수계산 기준
    • calendar영업일 캘린더
    • refDate기준일 (dayCounter 계산용)
  3. API
    • POST /xlfunction/ToCompoundRate
    • Excel Function·C#·Python 클라이언트에서 동일한 함수명으로 호출
  4. 샘플 요청 ToCompoundRate.json 
    {
  "args": [
    {
      "dateOrTimes": [
        "2025-01-02"
      ],
      "contiRate": [
        0.03
      ],
      "freqPerYear": 2,
      "dayCounter": "Act365Fixed",
      "calendar": "",
      "refDate": "2024-01-02"
    }
  ]
}
