CDS

CDS(notional, maturityTenor, fixedRate, tradeDate, swapCode, defaultCurveData, curveData, valueDate, outputType)
← 지원 함수 목록으로
  1. 개요

    신용부도스왑(CDS)의 NPV, 기본스프레드, 리스크 지표를 평가합니다.

  2. 입력 파라미터
    • notional명의금액
    • maturityTenor만기 테너 (예: 5Y, 10Y)
    • fixedRateCDS 고정 스프레드 (쿠폰 금리)
    • tradeDate거래 체결일
    • swapCodeCDS 컨벤션 코드 (예: cds_krw)
    • defaultCurveData부도확률 곡선 (신용 평가용)
    • curveData할인 곡선 데이터 (NPV 계산용)
    • valueDate평가일 (YYYY-MM-DD)
    • outputType출력 유형. pricing·cashflow·greeks·input_items 등
  3. API
    • POST /xlfunction/CDS
    • Excel Function·C#·Python 클라이언트에서 동일한 함수명으로 호출
  4. 샘플 요청 CDS.json 
    {
  "args": [
    {
      "label": "pricing",

    }
  ]
}
