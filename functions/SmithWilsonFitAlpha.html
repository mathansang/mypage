SmithWilsonFitAlpha

SmithWilsonFitAlpha(refDate, curveData, ufr, convergenceT, tolerance)
← 지원 함수 목록으로
  1. 개요

    Smith-Wilson 보간에 사용할 수령 파라미터 α를 시장 데이터에 맞게 추정합니다.

  2. 입력 파라미터
    • refDate기준일. 곡선 부트스트랩 및 할인 계산의 기준 날짜 (YYYY-MM-DD)
    • curveData연속복리 스팟(zeroRate) 곡선. time·zeroRate 또는 tenor·zeroRate
    • ufrUltimate Forward Rate. Smith-Wilson 장기 수령 금리
    • convergenceT수령 판정 만기 (년 단위)
    • toleranceα 추정 허용 오차
  3. API
    • POST /xlfunction/SmithWilsonFitAlpha
    • Excel Function·C#·Python 클라이언트에서 동일한 함수명으로 호출
  4. 샘플 요청 SmithWilsonFitAlpha.json 
    {
  "args": [
    {
      "refDate": "2024-01-02",
      "curveData": [
        [
          "tenor",
          "quote"
        ],
        [
          "1Y",
          0.03
        ],
        [
          "5Y",
          0.035
        ]
      ],
      "ufr": 0.042,
      "convergenceT": 20,
      "tolerance": 1e-08,
      "optionArg": ""
    }
  ]
}
