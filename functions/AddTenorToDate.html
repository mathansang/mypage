AddTenorToDate

AddTenorToDate(dates, tenors, calendar, lagDays)
← 지원 함수 목록으로
  1. 개요

    날짜에 만기 테너를 더해 새 만기일을 계산합니다.

  2. 입력 파라미터
    • dates기준 날짜 목록
    • tenors더할 만기 테너 목록 (3M, 1Y 등)
    • calendar영업일 캘린더 (예: KR, Null). 비어 있으면 NullCalendar
    • lagDays결제일 맀연 일수 (T+lag)
  3. API
    • POST /xlfunction/AddTenorToDate
    • Excel Function·C#·Python 클라이언트에서 동일한 함수명으로 호출
