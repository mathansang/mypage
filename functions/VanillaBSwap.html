VanillaBSwap

VanillaBSwap(notional, maturityTenor, basisSpread, swapSide, exchangeRate, tradeDate, swapCode, baseCurveData, quoteCurveData, fxSpot, valueDate, outputType)
← 지원 함수 목록으로
  1. 개요

    통화별 변동금리 지표가 다른 베이시스 스왑을 평가합니다.

  2. 입력 파라미터
    • notional명의금액
    • maturityTenor만기 테너 (예: 5Y, 10Y)
    • basisSpread통화별 변동 지표 간 베이시스 스프레드
    • swapSide레그 방향. rec(고정 수취)·pay(고정 지급)
    • exchangeRate고정 환율
    • tradeDate거래 체결일
    • swapCodeCCBS 컨벤션 코드 (예: ccbs_usdkrw_sofr_cd)
    • baseCurveData기준통화 인덱스 곡선 데이터 (time/tenor·zeroRate 또는 quote 테이블)
    • quoteCurveData상대통화 인덱스 곡선
    • fxSpot환율 (스팟)
    • valueDate평가일 (YYYY-MM-DD)
    • outputType출력 유형. pricing·cashflow·greeks·input_items 등
  3. API
    • POST /xlfunction/VanillaBSwap
    • Excel Function·C#·Python 클라이언트에서 동일한 함수명으로 호출
