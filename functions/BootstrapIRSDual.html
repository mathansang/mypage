BootstrapIRSDual

BootstrapIRSDual(refDate, swapQuoteData, curveType, discountCurveData)
← 지원 함수 목록으로
  1. 개요

    스왑 곡선과 별도 할인 곡선을 사용하는 듀얼 커브 부트스트랩을 수행합니다.

  2. 입력 파라미터
    • refDate기준일. 곡선 부트스트랩 및 할인 계산의 기준 날짜 (YYYY-MM-DD)
    • swapQuoteData스왑 견적 테이블. 헤더: tenor, type, quote 컬럼 (type은 deposite·swap 등)
    • curveType부트스트랩 대상 곡선 컨벤션 (필수). externalDiscount 설정 필요
    • discountCurveData외부 할인 곡선 데이터. time/tenor·zeroRate 또는 quote 형태의 곡선 테이블
  3. API
    • POST /xlfunction/BootstrapIRSDual
    • Excel Function·C#·Python 클라이언트에서 동일한 함수명으로 호출
