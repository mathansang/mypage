PricingAPI

파생상품 평가 API

고성능 평가 엔진을 REST API로 제공하여 외부 시스템과 손쉽게 연동할 수 있습니다.

Overview

서비스 개요

C++ 및 Python 기반의 파생상품 평가 엔진을 API 레이어로 노출합니다. 트레이딩 시스템, 리스크 관리 플랫폼, 사내 도구 등 다양한 환경에서 가격 산출과 민감도 분석을 HTTP 요청으로 수행할 수 있습니다.

Capabilities

평가 가능 항목

가격 산출

  • 옵션 · 선물 등 파생상품
  • 복합 구조 상품
  • 실시간 · 배치 요청

민감도 분석

  • Delta, Gamma, Vega 등 Greeks
  • 금리 · 변동성 민감도
  • 시나리오 기반 분석

연동 · 확장

  • REST API 표준 인터페이스
  • 커스텀 모델 연동
  • 엔터프라이즈 환경 지원
Documentation
