PricingAPI

파생상품 평가 API

기관급 평가 엔진을 클라우드 REST API로 제공합니다. 복잡한 인프라 구축 없이 한 번의 HTTP 호출로 정확한 가격과 리스크 지표를 받아보세요.

Overview

서비스 개요

PricingAPI는 C++ 및 Python 기반의 검증된 평가 엔진을 그대로 API 레이어로 노출합니다. 금리·통화·신용 등 다양한 자산군의 파생상품에 대해 가격 산출과 민감도 분석을 표준 HTTP 요청만으로 수행할 수 있어, 트레이딩 시스템·리스크 관리 플랫폼·사내 도구 등 어떤 환경에서도 손쉽게 통합됩니다.

라이브러리 빌드, 모델 캘리브레이션, 수치 계산 인프라를 직접 운영할 필요가 없습니다. 평가 로직은 서버에서 관리·업데이트되며, 사용자는 입력값을 전달하고 결과를 받기만 하면 됩니다. 실시간 단건 평가부터 대량 배치 평가까지 동일한 인터페이스로 처리합니다.
